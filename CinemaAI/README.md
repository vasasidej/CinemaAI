# CinemaAI

AI-бібліотека фільмів і серіалів з унікальним пошуком за цитатами та моментами.

## Опис
Веб-застосунок, який дозволяє шукати фільми не тільки за назвою, а й за цитатами, словами з діалогів або описом сцен.

## Структура
- 3 основні сторінки + авторизація
- Головна / Каталог (AI-пошук)
- Сторінка фільму (AI-моменти з тайм-кодами)
- Особистий кабінет / Обране
